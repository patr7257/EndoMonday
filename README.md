# EndoMonday

This project is going to be a fullstack app deployed on patrickrobel.dk subdomain as vercel project, similarly hosted and created as https://chess.patrickrobel.dk/ in repo https://github.com/patr7257/ChessSyndrome. Use ZRM Library which we will test and use as much as possible from, to create a fully functional modern webapp with magiclink + passkey login and env var email login allowlist. The app is an activities app for walking, running and biking, and will integrate with Strava developer apis and general apis for different features etc. my own personal strava is https://www.strava.com/athletes/144400147. Use strava APIs + MCP connectors to help generating a solid plan and idea of what the app should be able to do: https://www.strava.com/settings/api, https://www.strava.com/settings/mcp, https://developers.strava.com/, https://developers.strava.com/playground/. Help me research and investigate cool opportunities for fun integrations to the app. The app will need these following default pages: Home, Run, Stats, History, Settings and maybe more in case you have any ideas. Also, on Run we need to integerate or implement a nice interactive map + time tracking feature + some voice integration that tells me when i reach 1 km, 2 km etc while running. I will need a spotify integration directly in the app on phone, which should be a full pwa/mobile app with possible push notifications etc as ZRM library shows how is done. The interactive map should have a cool feature called draw your own route, which lets me try to draw a route on my map with the mouse or finger, and then it creates the route and tells me how far its going to be. I should be able to plan a combined biking + walking/running route and then the app splits up the total distances for me, so for example i can bike from here to the place where im going to go for a run, back to the bike and then bike home and the app will show the routes with different colors. In settings, i can change per user the colors of each different transport type. Start with only run, walk and bike.
